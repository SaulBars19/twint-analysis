# TWINT AG — Fundamental & Strategic Analysis

An interactive, browser-based research report on **TWINT AG**, Switzerland’s leading mobile-payment scheme. The project evaluates TWINT as a private financial-infrastructure company rather than as a publicly traded equity.

> **Research perspective:** payments, competitive strategy, economic moats, transaction growth, monetisation, risks and the 2026 strategic pipeline.

## Live report

After enabling GitHub Pages, the report will be available at:

`https://SaulBars19.github.io/twint-analysis/`

## Executive takeaway

TWINT combines a broad two-sided network, deep integration with Swiss financial institutions and near-universal domestic brand awareness. The analysis therefore classifies TWINT as strategically important national payment infrastructure with a wide qualitative moat.

However, TWINT is privately held and does not disclose the financial information required for a conventional valuation. The report consequently separates:

- **Strategic quality:** exceptional infrastructure and network position.
- **Standalone investability:** not directly investable and not reliably valuable from public information.
- **Key development to monitor:** adoption of recurring payments and digital invoicing as TWINT moves from user acquisition toward deeper monetisation and usage frequency.

## Methodology

Because TWINT is an unlisted company and does not publish a complete set of financial statements, this report uses an adapted research framework based on:

- public transaction and penetration KPIs;
- business-model and payment-rail analysis;
- qualitative economic-moat assessment;
- peer comparison with domestic account-to-account payment schemes;
- competitive and strategic analysis;
- scenario-based interpretation of future growth drivers.

No intrinsic valuation or price target is presented because the necessary revenue, profitability, cash-flow and capital-structure disclosures are unavailable.

## Run locally

### Simplest option

Open `twint_SIG_JSBR.html` directly in a web browser.

### Recommended option in VS Code

1. Install the **Live Server** extension.
2. Open this repository in VS Code.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The page will normally open at a local address such as `http://127.0.0.1:5500`.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `twint-analysis`.
2. Upload or push all files in this folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Save the configuration.

GitHub will then publish `twint_SIG_JSBR.html` as the project homepage.

Detailed commands are included in [`PUBLISH_FROM_VSC.md`](PUBLISH_FROM_VSC.md).
